# Log Analyzer

A small Python script I built to practice log analysis and threat detection.

It reads a system log file, flags suspicious activity, and alerts on users 
with too many failed login attempts.

## How to run
1. Make sure Python is installed
2. Run `python log_analyzer.py` in your terminal
